</div>

## 📖 Description

**MeowMeowBoom** is a 2D game developed in Unity as part of my university studies.

In this game, the player controls a cat in a dynamic chase mode. The objective is simple: move around the scenario, chase targets, and accumulate points for win. The game focuses on reflexes, movement precision, and score optimization.

This project helped me strengthen my understanding of 2D game development fundamentals, physics systems, and gameplay mechanics.

---

## 🎮 Gameplay Features

- 🐾 2D character movement  
- 🎯 Chase-based scoring system  
- 💥 Collision detection  
- 🧮 Score tracking  
- ⚡ Basic 2D physics implementation  

---

## 🛠️ Built With

- Unity (2D)
- C#
- Unity Physics System

## 🚀 How to Run the Project

Download the "Ejecutable" folder and execute the file **MeowMeowBoom.exe**
